# Video Recording Guide

This is a recording checklist, not a transcript. Replace each transcript placeholder with the
corrected words from the uploaded video and add the unlisted YouTube link to the manifest.

## Required opening for every video

1. Name OpenAI Codex and the task it assisted with.
2. State that the analysis and final decision are the student's.
3. State that the project is educational and not investment advice.

## Video 1 — system and thinking change, maximum 3:00

- Contrast a single historical optimum with the final mandate-and-stress process.
- Show one AI-assisted output that was checked independently using a test or visible calculation.
- Explain that all four stresses remain feasible, but the latest-36-month case moves an asset
  weight 25 points from the base and therefore blocks adoption.

## Video 2 — code walkthrough, maximum 5:00

- Walk through `load_estimates`, `portfolio_metrics`, and `search_lowest_risk`.
- Explain the net-return and reserve checks and why the grid has 1,771 portfolios.
- Run or show the thirteen tests, including the transaction-cost bridge, lineage boundary, and
  explicit invalid-input failures.

## Video 3 — committee presentation, maximum 5:00

- Open with `streamlit run app.py` already running.
- Move one control and read the mandate verdict.
- Present 60% SGOV / 40% SPGM, 6.74% net return, and 6.02% volatility.
- Compare the two baselines and the mandate benchmark.
- Explain that stability is measured from the base case. Distinguish the 25-point gate result from
  the descriptive 30-point cross-case SGOV range.
- Close with the reversal condition and monitoring triggers.

The completed narration is in `video-recording-script.docx`. After recording, correct each
plain-text transcript to the words actually spoken and replace every manifest placeholder with the
final YouTube URL, duration, timestamps, access check, and immutable ID.
